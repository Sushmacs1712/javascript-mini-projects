# Interview Prep Tracker

A simple web application to help track interview preparation, questions, topics, and progress in one place.

## Features

* Track interview questions
* Organize questions by topic
* Mark questions as completed
* Monitor preparation progress
* Simple and user-friendly interface

## Tech Stack

* HTML
* CSS
* JavaScript

## How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
3. Start adding and tracking your interview preparation.

## Future Improvements

* Add search and filtering
* Add progress statistics
* Store data using Local Storage
* Add more interview categories
