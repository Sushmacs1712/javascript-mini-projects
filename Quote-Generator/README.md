# Quote Generator

A simple and interactive web application that generates random quotes based on different categories.

## Features

* Generates random quotes by category
* Copy quotes to the clipboard
* Add quotes to favorites
* Remove quotes from favorites
* Saves favorite quotes using Local Storage
* Simple and clean user interface
* Responsive design

## Tech Stack

* HTML
* CSS
* JavaScript

## How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
3. Select a quote category.
4. Click **New Quote** to generate a quote.
5. Use **Copy Quote** to copy it to the clipboard.
6. Add your favorite quotes using **❤️ Add to Favorites**.
