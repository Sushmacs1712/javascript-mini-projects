# Quote Generator

A simple and interactive web application that generates random inspirational quotes with a click of a button.

## Features

* Generates random quotes
* Simple and clean user interface
* Interactive button functionality
* Responsive design

## Tech Stack

* HTML
* CSS
* JavaScript

## How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
3. Click the **Generate Quote** button to get a new quote.

## Project Purpose

Built to practice JavaScript fundamentals, DOM manipulation, event handling, and dynamic content updates.
